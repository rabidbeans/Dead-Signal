# Dead Signal

A co-op, top-down zombie shooter for phones. Rain, a dead city, a pistol.

**Play: https://dead-signal-game.web.app**: turn your phone sideways. Left
thumb moves, right thumb aims and fires (push to shoot, tap for a quick shot).

## Co-op
Tap **HOST CO-OP** and send the 4-letter code to up to three friends. They
tap **JOIN WITH CODE** and type it in. Firebase handles the code; the game
itself runs phone to phone.

## Level 1: The Checkpoint
Hold an abandoned police roadblock at a rain-soaked crossroads through five
waves until the evac signal comes through. Some of the dead shamble, and some
lurch at you without warning.

## Running it locally
```
npm install
npm run dev
```
Then open http://localhost:5173. Use WASD and the mouse on a computer.

## How the art is made
Everything is generated by scripts in `tools/`:
- **Characters:** MakeHuman's CC0 human body, sculpted and baked in Blender into game-ready zombies and survivors.
- **Props and pistol:** modelled in Blender.
- **Textures and sounds:** synthesised in Python.

`CLAUDE.md` has the full pipeline.
